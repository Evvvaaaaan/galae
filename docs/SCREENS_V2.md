# 갈래 화면 구성 v2

작성일 2026-11-02. 기존 화면과 흐름(`APP_FLOW.md`)은 그대로 두고, 디자인을 새로 하고 생각 탭을 더했다.

## 원칙

- 흰 배경, 푸른 선, 명조 제목. 기존 색과 선 모티프를 그대로 쓴다.
- 설명 문구, 라벨, 배지, 안내 각주를 두지 않는다. 텍스트는 콘텐츠와 꼭 필요한 버튼만 둔다.

## 탭

| 탭 | 경로 | 역할 |
| --- | --- | --- |
| 오늘 | `#/today` | 오늘의 질문 |
| 생각 | `#/feed` | 철학 역설 피드 |
| 질문 | `#/archive` | 질문 모아보기 |
| 그룹 | `#/groups` | 그룹 나눔 |
| 기록 | `#/records` | 나의 기록 |

탭 화면의 우측 상단 아이콘은 설정(`#/settings`)으로 간다.

## 화면

| 화면 | 경로 | 보이는 것 |
| --- | --- | --- |
| 시작 | 첫 방문 | 선 모티프, 갈래, 한 줄 소개, 시작하기, 소셜 로그인(준비 중이라 비활성) |
| 온보딩 | 시작하기 | 3장, 건너뛰기 |
| 오늘 | `#/today` | 날짜. 질문 카드(선택지 수만큼 갈라지는 선 모티프, 번호, 참여 수, 질문). 버튼. 숫자 띠, 그룹, 지난 질문 |
| 질문 모아보기 | `#/archive` | 검색, 상태 필터, 주제 필터, 질문 목록 |
| 생각 | `#/feed` | 위아래로 넘기는 주제. 한 화면에 주제 제목, 모든 글, 출처. 하루 5개 뒤에는 선 모티프만 있는 끝 화면 |
| 선택 | `#/question/:id/answer` | 진행 선, 질문, 선택지, 이유, 제출 |
| 결과 | `#/question/:id/result` | 선택별 비율 막대. 내 선택은 색으로만 구분. 비율 옆 화살표로 코멘트 보기 |
| 선택지 코멘트 | `#/question/:id/result/:choiceId` | 위에 질문 카드(질문, 그 선택지와 비율), 아래에 댓글. 내가 고른 선택지면 내 이유가 맨 위 댓글 |
| 확장하기 | `#/question/:id/reading` | 관점별 해설(성경·철학·오늘의 연구). 성경은 구절과 장절. 성경 외 관점은 자리 표시용 목업 |
| 완료 | `#/question/:id/done` | 선 모티프, 내 선택, 나누기, 나의 기록, 다른 질문 |
| 나누기 | `#/question/:id/share` | 공유될 내용, 그룹 선택, 저장, 외부 공유, 그룹에서 보기 |
| 기록 | `#/records` | 프로필, 달력, 내 생각의 방향, 필터(전체·공유·댓글), 답한 질문 또는 내 댓글 |
| 기록 상세 | `#/records/:id` | 질문, 선택, 이유, 공유 중인 그룹, 나누기·다시 보기 |
| 내 생각의 방향 | `#/report` | 주제별 답한 수 |
| 그룹 | `#/groups` | 내 그룹, 만들기, 참여 |
| 그룹 만들기 | `#/groups/new` | 색, 이름, 소개 |
| 그룹 참여 | `#/groups/join` | 초대 코드 |
| 그룹 상세 | `#/groups/:id(/:questionId)` | 소개, 질문 선택, 답하기 전에는 질문과 답하기, 답한 뒤에는 그룹원의 선택과 이유 |
| 멤버 | `#/groups/:id/members` | 초대 코드, 복사, 멤버, 나가기(한 번 더 확인) |
| 그룹 설정 | `#/groups/:id/settings` | 그룹장만. 색, 이름, 소개 수정. 멤버 화면에서 진입 |

## 흐름

기존과 같다.

```
시작 → 온보딩 → 오늘
선택 → 결과(→ 선택지 코멘트) → 확장하기 → 완료 → 나누기
```

## 데이터

- 역설 카드: `content/paradoxes.json`. `checked`가 있는 주제만 하루 5개 보인다. 개발 서버(`npm run dev`)에서는 검증 전 주제도 보인다.
- 저장 구조와 `localStorage` 키는 기존 그대로다.
- 설정의 기록 초기화는 시연·개발용이다. 답변 기록만 지운다. 서버 연동 시 제거한다.
