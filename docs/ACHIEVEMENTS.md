# 세계수와 열매 업적

2026-11-04 기준

## 개요

홈 맨 위에는 답변 하나마다 푸른 선이 한 가닥씩 늘어나는 세계수가 있습니다. 정해진 순간마다 나무에 고리 열매가 맺힙니다. 열매 하나가 업적 하나이며, 업적은 모두 15개입니다.

홈 순서: 세계수 → 출석 카드 → 질문 카드 → 그룹 카드. 질문 카드의 세 갈래 그림과 생각 카드는 홈에서 뺐습니다.

## 세계수

- 답변 하나는 뿌리에서 줄기를 지나 가지 끝까지 이어지는 선 한 가닥입니다.
- 가지는 줄기 꼭대기 한 점에서 부채꼴로 퍼집니다. 뿌리는 아래로 낮고 넓게 퍼집니다.
- 첫 선은 가운데로 올라갑니다. 그다음 선부터는 왼쪽과 오른쪽을 번갈아 빈 곳을 메웁니다. 고른 선택지는 가지 방향에 영향을 주지 않습니다.
- 선은 모두 옅은 푸른색입니다. 새 선은 남색으로 그려진 뒤 서서히 푸른색으로 돌아갑니다.
- 선이 쌓일수록 나무 뒤의 빛이 조금씩 진해지고, 선 하나하나는 가늘어집니다.

### 열매

- 모양: 채우기 없는 작은 고리. 옅은 푸른 테두리이며, 고리 가장자리가 가지 끝에 닿습니다.
- 새로 맺힌 열매는 남색으로 나타났다가 서서히 옅은 색으로 돌아갑니다. 남색으로 남아 있지 않습니다.
- 위치: 열매도 맺힌 순서대로 왼쪽과 오른쪽을 번갈아, 그 방향에 가장 가까운 가지 끝에 답니다.
- 거절된 안: 노란 열매, 가운데 남색 점, 채운 별빛.

### 연출

- 답한 뒤 홈에 처음 돌아왔을 때만 새 선이 뿌리부터 그려집니다. 그때 열매가 새로 맺혔으면 선이 다 그려진 뒤 나타납니다.
- 다시 홈에 오면 그려진 상태로만 보입니다. 기기에 저장된 마지막으로 본 선 개수(`galae.treeSeen`)로 구분합니다.
- 업적을 달성하면, 다음에 홈에 왔을 때 그 열매가 맺힙니다. 고리가 남색으로 작게 피어나며 물결이 한 번 번지고, 나무 아래에 이름과 설명 한 줄이 떠올랐다 사라집니다. 그 뒤 고리는 서서히 파란색으로 돌아갑니다.
- 새 선이 있으면 선이 다 그려진 뒤에, 답변이 아닌 일(댓글, 그룹 만들기 등)로 맺힌 열매는 홈에 오자마자 맺힙니다.
- 한 번에 여러 개면 하나씩 차례로 맺히고 이름도 차례로 보여 줍니다. 맺히는 모습을 이미 본 열매는 기기에 저장(`galae.fruitSeen`)해 다시 보여 주지 않습니다.
- 팝업, 축하 문구, 버튼은 쓰지 않습니다.

## 이름 짓기 규칙

- 명사 하나로 끝나는 이름을 씁니다. "~하다", "~하는 자" 같은 꼴은 쓰지 않습니다.
- 시간이 쌓이는 업적(연속 출석)은 나무 단어를 씁니다. 활동이 쌓이는 업적(답변, 나눔, 댓글)은 사람 칭호를 씁니다. 예외로 30일 연속은 "수행자", 지난 질문은 "여행자"를 씁니다.
- 처음 답한 "첫 가지"와 답변 200개 "세계수"로 나무가 처음과 끝을 닫습니다.
- 성경을 콘셉트의 중심에 두지 않습니다. 성경은 콘텐츠 속 여러 관점 중 하나입니다.
- 확장하기는 질문 흐름에 항상 들어 있어서 업적에서 뺐습니다.
- 설명 한 줄은 모두 "~했어요"로 끝나는 담백한 말투로 맞춥니다.

## 판정 기준

| 업적             | 앱 데이터로 세는 방법                                  |
| ---------------- | ------------------------------------------------------ |
| 답변 수          | `answers` 중 `submitted`인 답변 수                     |
| 연속 출석        | 답한 날짜(`answeredOn`)가 하루도 빠짐없이 이어진 날 수 |
| 지난 질문에 답함 | 답한 날짜가 그 질문의 날짜와 다른 답변                 |
| 그룹 나눔        | 답변의 `sharedWith`가 비어 있지 않은 답변 수           |
| 댓글             | `comments` 개수                                        |
| 공감             | `likes` 개수                                           |
| 그룹 만들기      | 사용자가 만든 그룹(`owner`)이 있는지                   |

답변은 선택지를 고르고 [선택하기]를 누른 것으로 셉니다. 이유는 쓰지 않아도 됩니다.

업적을 처음 달성하면 날짜(`on`)를 `achieved`에 저장합니다. 한 번 맺힌 열매는 공감을 취소해도 사라지지 않습니다. 연속 출석은 지금까지 가장 길게 이어진 날 수로 셉니다.

## 마이페이지 표시

- 위치: 기록 탭, 프로필 아래
- 맺은 열매만 고리로 한 줄에 늘어놓습니다. 아직 맺지 않은 열매는 보여주지 않습니다.
- 고리를 누르면 이름, 날짜, 설명 한 줄이 나옵니다.

```
탐험가
11월 4일 · 10번째 답을 남겼어요
```
